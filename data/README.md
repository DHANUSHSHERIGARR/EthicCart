# Data

This directory contains datasets and data-processing artifacts used by EthicCart.

## Data Sources

The project will use publicly available product, review, and ethical/sustainability evidence sources.

The primary product and review dataset under investigation is Amazon Reviews'23.

Relevant sustainability and ethical evidence sources include sources such as EPEAT and TCO Certified.

## Data Policy

Large raw datasets will not be committed to GitHub.

Instead, this directory will contain documentation, scripts, and small sample datasets where appropriate.

## Data Pipeline

Raw Data
→ Cleaning
→ Processing
→ Feature Engineering
→ ML Dataset
