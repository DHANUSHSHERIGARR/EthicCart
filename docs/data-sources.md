# EthicCart — Data Sources

## 1. Amazon Reviews'23

Purpose:
- Product metadata
- Product descriptions
- Product categories
- Prices
- Ratings
- Customer reviews

Primary identifier:
- Parent ASIN

Used for:
- Product dataset
- Review dataset
- NLP analysis
- Product similarity/recommendation

Source:
https://amazon-reviews-2023.github.io/

## 2. EPEAT

Purpose:
- Electronics sustainability and environmental evidence
- Product-level certification information
- Sustainability criteria
- Responsible supply-chain evidence

Relevant product categories:
- Computers and displays
- Mobile phones
- Other supported electronics

Used for:
- Environmental features
- Sustainability features
- Supply-chain evidence
- Certification evidence

Source:
https://www.epeat.net/

## 4. IEEE P7000-Series

Purpose:
- Ethical-system design framework

Used for:
- Identifying ethical values
- Defining system requirements
- Designing transparency, privacy, fairness, accountability and human-oversight considerations
- Structuring the ethical evaluation methodology

Important:
EthicCart is IEEE-informed and does not claim IEEE certification.
