# EthicCart

## Ethical Product Recommendation & Evaluation System

EthicCart is an AI-powered system designed to evaluate consumer products using an ethical evaluation framework and recommend ethically preferable alternatives.

## Project Status

Under Development

## Core Objectives

- Evaluate products across multiple ethical dimensions.
- Classify products as BUY, DON'T BUY, or INSUFFICIENT EVIDENCE.
- Explain model decisions using Explainable AI.
- Recommend similar products with stronger ethical profiles.
- Incorporate relevant principles from the IEEE P7000-series standards.
